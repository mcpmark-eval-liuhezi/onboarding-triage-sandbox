# onboarding-triage-sandbox

Sandbox repo for new-hire pull-request triage drills. Expect frequent resets.

## Purpose

A safe place to practise the full pull-request triage pass: finding open PRs,
reading the diff, bringing the branch up to date with `main`, checking linked
sub-issues, and drafting review comments without touching anything real.
